# Ayan Butt — updated GitHub Pages portfolio

Updated from the supplied ML/AI résumé. Includes Urdu **ایان**, a new responsive design, FlyRank experience and case study, five featured projects, education, skills, corrected LinkedIn link, and a downloadable résumé.

## Publish
1. Extract this ZIP.
2. Upload the **contents** of `ayanbutt1013.github.io-main/` into the root of your `AyanButt1013/ayanbutt1013.github.io` repository. Replace the existing files and include the entire assets folder and PDF. Do not upload the ZIP itself or nest the website inside an additional folder.
3. Commit to your GitHub Pages branch. Under Settings → Pages, use Deploy from a branch and the repository root if needed.
4. Wait for GitHub Pages deployment, then open https://ayanbutt1013.github.io/.

No build step or backend is needed. The source is updated; the live GitHub website has not been published from this environment.

## Preview locally
Run `python3 -m http.server 8765` in the extracted directory and visit http://localhost:8765/. You can also open index.html directly.
